# AI Cost Optimization

- Read current state and canonical docs before repository-wide exploration.
- Run targeted tests first and expand only when required.
- Reuse trustworthy prior test evidence.
- Avoid recreating equivalent fixtures.
- Keep reports concise and link to evidence.
- Make one focused authorized change at a time.
- Revalidate earlier evidence when code, environment, schema, or runtime behavior changes.
- Do not repeat screenshots or full suites solely to demonstrate unchanged behavior.
