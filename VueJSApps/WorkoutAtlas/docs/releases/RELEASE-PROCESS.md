# WorkoutAtlas Release Process

1. Verify branch and working tree.
2. Confirm package versions and QA evidence.
3. Separate code complete, tested, live tested, user accepted, and released states.
4. Review protected data and migration impact.
5. Obtain explicit user/authorization approval for acceptance and deployment.
6. Push/deploy only under an approved workflow.

Documentation-only work does not create a release or bump versions.
